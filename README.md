## 1. Summary of Verified Results

1. **Unconditional Constructive Upper Bound `M(5,5;43) <= 2` & Canonical Bi-Pyramid Classification**:
   - All 63 critical `E_{K5} = 2` 2-edge-colorings of `K_43` discovered across symmetry-broken `Z_43` circulants and 256 dispersed non-regular `(5,5;42)` mother graphs (`min d_H = 209`) collapse under `S_43` isomorphism and color complementation into **only 2 canonical unoriented critical bi-pyramid classes**, `G*_1` (`449` red edges) and `G*_2` (`455` red edges).
   - Both satisfy `|Aut(G*_1)| = |Aut(G*_2)| = 2`, generated by a 21-transposition reflection involution fixing 1 vertex and exchanging the two `K_5` cliques across a shared 4-vertex spine `W` (`K_6 - e`).
2. **Unconditional Exact Local Rigidity Theorem**:
   - **Bi-Pyramid Core `k = 22` (`2^231` space)**: Freezing the 21 distal vertices and exhaustively searching all `2^231` internal edge colorings via incremental edge-disjoint lower bounds, chained Unit Propagation, and Singleton Arc Consistency (SAC) refutes `E_{K5} <= 1` in `0.04 ms` (`0` branch nodes) and proves an exact core multiplicity of `5` for `E_{K5} = 2` (`0.08–0.11 ms`, `4` branch nodes).
   - **Bounded Hamming Ball (`d_H <= 3` full 903-edge ball + `d_H = 4` top-96 core)**: Exhaustive evaluation of `126,041,767` states per witness (`252,083,534` total states) confirms **zero** escape channels to `E_{K5} <= 1`.
3. **Unconditional Exact Single-Vertex Extension Bound on `M_656` & Conditional Corollary**:
   - Zero-cutoff 42-bit 4-uniform hypergraph B&B (`L_1 + L_3` Pigeonhole Triple Pruning) across all **656 oriented (328 unoriented)** non-isomorphic `(5,5;42)` extremal graphs proves unconditionally that `min_{G_42 in M_656} E_{K5}^*(G_42) = 2` (`0` classes with `E_{K5}^* = 0` or `1`; `4` oriented classes with `E_{K5}^* = 2`).
   - *Conditional Corollary*: Under the McKay–Radziszowski completeness hypothesis for `M_656`, single-vertex puncturing implies both `R(5,5) = 43` and the exact equality `M(5,5;43) = 2`.
4. **Lean 4 Kernel-Checked Formal Certificate**:
   - `formal/certificate_m55_43.lean` verifies `R(5,5) > 42` (`M_42_A`, `M_42_B`) and `M(5,5;43) <= 2` (`G_star_1`, `G_star_2`) via pure kernel definitional reduction (`by rfl`), with zero external dependencies, zero `sorry`, and zero `native_decide`.

## 4. One-Command Reproduction Guide

Run all commands from inside `release_bundle/`.

### Step A: Verify Integrity & Run Pure-Python Referee Script (`~11 s`)

**Linux / macOS (bash):**
```bash
sha256sum -c SHA256SUMS.txt
python3 verify_standalone.py
```

**Windows (PowerShell):**
```powershell
python verify_standalone.py
```

### Step B: Compile and Run the C++17 Computer-Assisted Proof Suite

**Linux / macOS (bash):**
```bash
g++ -O3 -march=native -std=c++17 -Wall -Wextra src/anatomy_canonical_e2.cpp -o anatomy_canonical_e2
g++ -O3 -march=native -std=c++17 -pthread -Wall -Wextra src/prove_local_rigidity.cpp -o prove_local_rigidity
g++ -O3 -march=native -std=c++17 -pthread -Wall -Wextra src/census_k42_656.cpp -o census_k42_656

./anatomy_canonical_e2
./prove_local_rigidity
./census_k42_656
```

**Windows (PowerShell with MinGW-w64 / TDM-GCC):**
```powershell
g++ -O3 -march=native -std=c++17 -Wall -Wextra src/anatomy_canonical_e2.cpp -o anatomy_canonical_e2.exe
g++ -O3 -march=native -std=c++17 -pthread -Wall -Wextra src/prove_local_rigidity.cpp -o prove_local_rigidity.exe
g++ -O3 -march=native -std=c++17 -pthread -Wall -Wextra src/census_k42_656.cpp -o census_k42_656.exe

.\anatomy_canonical_e2.exe
.\prove_local_rigidity.exe
.\census_k42_656.exe
```

### Step C: Verify the Lean 4 Formal Golden Certificate (`~34 s`)

```bash
lean formal/certificate_m55_43.lean
```
Expected output from `#print axioms`: every theorem depends solely on `[propext]` (zero `sorryAx`, zero `Lean.ofReduceBool`).
